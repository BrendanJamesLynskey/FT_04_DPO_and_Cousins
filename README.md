# FT 04 — DPO and Cousins

A rigorous comparison of the DPO family of preference optimisation algorithms: DPO's derivation as implicit reward maximisation, the beta hyperparameter and reference model role, IPO's fix for preference saturation, KTO's Kahneman-Tversky formulation that needs no paired comparisons, ORPO's reference-free single-stage training, and GRPO's group-relative reward as used in DeepSeek-R1. Includes a decision tree for choosing among them.
